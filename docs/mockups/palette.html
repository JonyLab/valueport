两点值得收口 建议

1. 高亮蓝没进 token。 #31679b 在 CTA / 选中 / 链接 / eyebrow 里硬编码 15 次,hover #2b5a87、浅蓝底 #f2f6fb、描边 #cfddec 也都是裸 hex。建议提为 --accent(或 --cta / --cta-hover / --cta-soft)一族,改色一处生效。

2. 有两套"主色"并存。 深墨 --ink 用于结构 chrome(主按钮、分段、tab 激活),石板蓝 #31679b 用于功能行动(估值 CTA、选中、链接)。目前是"深墨=结构 / 蓝=行动"的隐性分工——基本自洽,但没成文。要么明确写下这条规则,要么二选一统一,避免日后乱用。
