# 看板单页化（查看/编辑合一）— 设计文档

- 日期：2026-06-12
- 状态：已确认（编辑交互 = 弹窗）
- 前置：多用户系统（2026-06-11 spec）已上线

## 目标

`/b/<slug>` 成为唯一的看板页：访客纯查看；看板主人在同一页面上直接管理标的（弹窗添加/编辑），并通过右上角「设置」进行高级配置。

## 角色与能力

| 身份 | `/b/<slug>` 行为 |
|---|---|
| 访客（未登录） | 纯查看（现状公开页），无任何编辑 UI |
| 看板主人（已登录且 `/api/me` 的 slug 与当前页一致） | 查看 + 弹窗编辑标的 + 右上角设置抽屉 |
| 已登录但非本看板主人 | 等同访客，右上角显示「我的看板」链接 |

身份判定纯 UI 层（加载时调 `/api/me`）；所有写接口服务端按 cookie 校验，无新增安全面。

## 交互结构（主人模式）

1. **标的管理（图表流内）**
   - 每个钟摆卡片右上角悬浮「编辑」按钮 → **弹窗**（modal）打开该标的表单
   - 图表流末尾虚线「＋ 添加标的」卡片 → 同一弹窗（空表单）
   - 弹窗内容：代码联想框、合理低/高点、安全边际% + chips、极度高估% + chips、保存状态；底部「移除」（仅已有标的）与「完成」
   - 改动沿用防抖自动保存（_saving/_pendingSave 串行），钟摆实时摆动预览
   - 新增标的在「完成/关闭」时仍未选定代码（从未保存）→ 丢弃该卡片
2. **设置抽屉（右上角 ⚙ 设置）**
   - 右侧滑出 drawer，两个 tab：
     - 页面：文案（小标题/大标题/说明）+ 色块配色（实时预览）
     - 看板：名称、Slug、完整分享网址 + 复制
   - Slug 保存成功后 `history.replaceState` 同步地址栏为新 `/b/<slug>`
   - 抽屉底部「退出登录」
3. 视觉沿用 shadcn(zinc) 主题；弹窗/抽屉按 shadcn Dialog/Sheet 形态。

## 路由收敛

| 路由 | 变化 |
|---|---|
| `/b/<slug>` | 唯一看板页（双模式） |
| `/app` | Worker 302：有会话 → 自己的 `/b/<slug>`；无会话 → `/login`；`public/app.html` 删除 |
| `/login` `/register` | 成功后跳自己的 `/b/<slug>`（取 `/api/me` / 注册返回的 board.slug） |
| `/owner` | 不变 |

## 改动面

- **后端**：仅新增 `GET /app` 重定向（+ 对应测试）。
- **前端**：`index.html` 合并编辑能力（弹窗、抽屉、combobox、chips、自动保存逻辑自 app.html 平移）；`login/register` 跳转目标改 `/b/<slug>`；删除 `app.html`；README 入口更新。
- 访客视觉基本不变（页面底色随 zinc 主题微调）。
