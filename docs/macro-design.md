# 宏观看板（Macro）设计 · ValuePort

> 研究与设计稿，不涉及代码改动。参考了 `DESIGN.md`、`public/shared/core.js`（ZONES 五区间）、`public/shared/gauge.js`（钟摆 Gauge），以及 `src/` 里已有的数据接入（eastmoney / longbridge / finnhub）。

---

## 1. 一句话原则

**这一页不预测天气，只量水位：看整个市场贵不贵、利率这股"引力"有多重，然后回到你自己的击球区。绝大多数时候它告诉你的是："今天什么都不用做。"**

推论：
- 页面上**没有**"今天"。最短的时间尺度是"月"，默认视图是 20 年以上。
- 每个数字都要回答"它在自己历史里处于什么位置"，不报绝对值涨跌。
- 页面的终点是用户自己的标的，不是宏观结论。宏观只决定"该多勤快地去翻自选"，不决定"买什么"。

## 2. 大师视角

### 巴菲特 · 看水位和引力，不看天气预报

**会看：**
- **整体市值 / GDP**。他在 Fortune 2001 年的《Warren Buffett on the Stock Market》（与 Carol Loomis 合写）里说这可能是衡量任一时点估值水平最好的单一指标，并举了 1999 年与 1982 年的两极。
- **长期利率**。Fortune 1999 年那篇关于股市的演讲稿，以及多次股东大会（如 2013、2020、2021 年）里，他都把利率比作作用于所有资产价格的"引力"：利率越高，未来现金流的现值越低。
- **通胀**。1977 年 Fortune 的《How Inflation Swindles the Equity Investor》：通胀是对股东回报的隐形税，股本回报率长期被限制在一个水平附近。
- **市场情绪的两极**（只看两极）。1986 年致股东信里"别人贪婪时恐惧、别人恐惧时贪婪"，以及 2008 年 10 月纽约时报评论《Buy American. I Am.》——都是在极端水位时出手，不是在中间择时。
- **自下而上的"找不到东西买"**。1969 年合伙人信里他因找不到便宜标的解散合伙企业；伯克希尔的现金堆积本身就成了一个事后的市场温度计。

**不会看：**
- 经济与市场预测。1994 年股东大会、2013 年致股东信（"形成宏观观点或听别人的宏观、市场预测，是浪费时间"的大意）、以及历年信中"我们不读经济预测"的表述。
- 美联储下一次会议、下季度 GDP、短期市场走向。

### 芒格 · 反过来想：先别犯蠢

**会看：**
- **会让人犯蠢的环境信号**：杠杆、狂热、"这次不一样"。来源：1995 年哈佛演讲《The Psychology of Human Misjudgment》（误判心理学，尤其社会认同、过度乐观）、《穷查理宝典》（Poor Charlie's Almanack）中的反向思考与检查清单。
- **自己的行为**：芒格多次在 Daily Journal 年会上说，他们从未因宏观判断做过决定；钱是在"等待"中赚到的（"坐着不动"的大意）。所以页面应提示"你想动的冲动从哪来"。
- **复利不能被不必要地打断**：大幅回撤时最大的风险是被迫卖出（杠杆、资金期限错配），而不是价格本身。

**不会看：**
- 宏观经济学本身作为决策输入（他说宏观是"我们干脆不做决定"的领域，大意）。
- 任何需要频繁看的指标——频繁看本身就是诱因。

### 李录 · 长期文明坐标 + 短期皆为噪音

**会看：**
- **长周期的结构性趋势**：《文明、现代化、价值投资与中国》（2020，中信出版社）把现代化归结为科技 + 自由市场经济带来的持续复利增长，中国处于这条曲线的追赶段。他关心的是城镇化率、人均 GDP 与发达国家的差距、教育和科研投入、制度变化这类"十年级别"的变量。
- **市场整体的估值与"本金永久损失"风险**：2015 年北大光华讲座《价值投资的知识结构和中国的价值投资实践》强调：风险不是波动，而是永久损失；价值投资者应把市场当作服务者而非指导者。
- **中美比较**：他多次在公开演讲和博客（"李录的博客"）中对比中美的发展阶段与估值水平，以此判断"长期坐标"是否被市场情绪扭曲。

**不会看：**
- 短期宏观数据与政策猜测。他在多篇文章和讲座中明确表示短期宏观无法预测、属于能力圈之外，价值投资者"只需要知道自己不知道"。
- 任何把宏观观点直接翻译成交易的东西。

### 三人合起来的共识
| 维度 | 共识 |
|---|---|
| 时间尺度 | 十年、周期，而不是季度 |
| 有用的宏观 | 整体估值水位、长期利率、通胀趋势、极端情绪 |
| 无用的宏观 | 预测、新闻、会议、短期数据、技术形态 |
| 宏观的作用 | 调节"多勤快地找"和"安全边际要多厚"，不决定"买哪只" |
| 最好的市场指标 | 你自己按企业价值算出来的击球区里有多少名字 |

## 3. 页面信息架构（自上而下）

全页用一个**市场切换胶囊**（美股 / 港股 / A 股 / 全部），默认"全部"时每节显示三市场小多图（small multiples），切单市场时展开大图。

### ① 页头：一句话判定 + "你不需要做什么"
- **展示**：`h1` 一句话，如"美股处在历史高位水位，港股和 A 股在合理偏低。你的自选里有 3 只进入击球区。"下方一行灰字：`下次数据更新：11 月 1 日 · 上次你来看是 23 天前`。
- **形态**：纯文字，大字号 Outfit 400；右侧一个小徽章 `本月无需行动` / `值得翻一翻自选`（暖黄）。
- **为什么**：先给结论，压住"往下翻找刺激"的冲动；"上次来看是 N 天前"用来温和地反对频繁查看。
- **数据**：由下方各节计算得出；访问时间存 D1 或 localStorage。

### ② 市场水位钟摆（核心，三市场各一个）
- **展示**：每个市场一个复用 `Gauge` 的钟摆，指针 = **综合估值百分位**（该市场若干估值指标对自身长历史的百分位均值）。五区间沿用 ZONES：
  - 击球区 0–10 分位 · 低估 10–30 · 合理 30–70 · 高估 70–90 · 泡沫区 90–100
  - 实现上直接传 `anchors = [0, 10, 30, 70, 90, Infinity]`，"价格"换成百分位即可，`priceToPhi` 不用改。
- **钟摆下方**列出组成项（每项一行五段条 + 当前百分位）：
  - 美股：总市值/GDP、Shiller CAPE、盈利收益率 − 10 年期实际利率
  - 港股：恒指 PE、恒指 PB、恒指股息率（倒序）
  - A 股：总市值/GDP、沪深 300 / 中证全指 PE 与 PB、股债性价比（沪深 300 E/P − 10 年国债）
- **为什么**：这就是巴菲特说的"水位"。百分位比绝对值诚实，且直接和现有五区间语义对齐，用户无需学新概念。
- **注意事项（写在 ⓘ 里）**：美股总市值/GDP 因跨国收入长期上移；港股不放市值/GDP（大量内地公司，分母失真）；百分位取决于历史窗口，窗口要写明（如"1990 年至今"）。
- **数据/频率**：月度（月初 cron 刷新）。

### ③ 引力：长期利率与股票的相对吸引力
- **展示**：一张 20–30 年长期折线（月度点），两条线：**股票盈利收益率**（1/CAPE 或 1/PE）与**10 年期国债收益率**（美股另画实际利率 TIPS），中间的差（风险溢价）用浅色面积填充。当前值标在右端，配一行文字："现在买股票每 100 元得到约 X 元盈利，买 10 年国债得到 Y 元。"
- **形态**：长区间折线，不提供 1 天/1 周/1 月选项；只有 `10 年 / 20 年 / 全部`。
- **为什么**：巴菲特的"引力"。风险溢价收窄 = 安全边际应要求更厚，而不是"要卖"。港股联汇制度下用美国 10 年期作为引力（写明原因）。
- **数据/频率**：美 FRED `DGS10`、`DFII10`；中国 10 年国债（eastmoney 中美国债收益率接口，或中债）。月度。

### ④ 通胀趋势
- **展示**：小多图三格（美 CPI 同比、中国 CPI 同比与 PPI 同比、香港综合 CPI），10 年线，一条 2% 参考虚线。不显示"本月数据超预期"之类。
- **为什么**：巴菲特 1977 年那篇文章：通胀抬高必要回报率、侵蚀实际回报；李录关心 PPI 作为中国工业企业盈利的长期背景。
- **数据/频率**：FRED `CPIAUCSL`；国家统计局；香港政府统计处。月度。

### ⑤ 信用与杠杆："有没有人在犯蠢"（芒格节）
- **展示**：两个小型百分位条：美国信用利差（Moody's Baa − 10Y，FRED `BAA10Y`，长历史可用）；A 股两融余额 / 流通市值。只显示**极端两端**才高亮（<10 或 >90 分位），中间状态灰掉写"正常"。
- **为什么**：信用利差极宽 = 别人恐惧（2008、2020 那种时刻）；杠杆极高 = 别人贪婪。只在两极有意义，所以只在两极说话。
- **数据/频率**：FRED 周/月；两融来自 eastmoney 或交易所，月度取月末值。

### ⑥ 你的击球区（本页最重要的落点）
- **展示**：
  - 大数字：`自选中 3 / 42 只处于击球区，7 只低估`（分市场统计）。
  - 一条按 ZONES 着色的**分布胶囊**（复用看板的分布胶囊组件），显示自选在五区间的数量分布。
  - **自下而上温度计**：自选击球区+低估占比的历史折线（需每日/每周把快照写入 D1），与上面的市场钟摆并排——"市场的水位"和"你的机会数"两种视角互相印证。
  - 下方列出处于击球区的标的卡（logo + 名称 + 距离击球区价位），点击进详情。
- **为什么**：巴菲特"找不到东西买就是市场贵"的自下而上版本。宏观页的唯一行动出口就在这里：市场便宜时，提示"去更新这些标的的估值"；市场贵时，提示"击球区里仍有的名字更要复核护城河"。
- **数据**：现有 items / 估值数据，零外部依赖。

### ⑦ 反向清单（Munger checklist）
- **展示**：5–6 行静态+动态检查，每行一个勾/叉：
  - 组合里有多少仓位处于高估/泡沫区（来自资产页）
  - 是否使用了融资杠杆（来自券商持仓，若可得）
  - 单一持仓是否超过你自己设的上限
  - 过去 30 天的交易次数（越多越要问为什么）
  - 你今天来这一页，是因为数据更新，还是因为新闻？（自问，不计分）
- **为什么**：芒格的"反过来想"：先列出会导致永久损失的方式，再逐一避免。
- **形态**：文本清单，`--r-lg` 子卡。

### ⑧ 长期坐标（李录节，年度更新）
- **展示**：小多图：中国城镇化率、中国人均 GDP 占美国比例（PPP 与现价两条）、研发投入占 GDP、美国非金融企业利润占 GDP。30–50 年尺度，年度数据点。
- **加一个"我的长期假设"文本框**：用户每年写一次自己对各市场的长期判断 + "什么证据出现会证明我错了"（反向），到期提醒复盘。
- **为什么**：李录所说的现代化曲线与追赶空间；这一节刻意慢、刻意少，作为全页的"压舱石"。
- **数据/频率**：世界银行 WDI API（免费）、国家统计局、FRED（`CP` / `GDP`）。年度。

### ⑨ 页脚：一条原则
- 每次访问轮换一条**短的意译**原则（不长引），标注出处，如"利率之于资产价格，如同引力之于苹果 —— 巴菲特，1999/2013 等"、"反过来想 —— 芒格"、"知道自己不知道 —— 李录"。
- 一行灰字："数据按月更新。这一页每月看一次就够了。"

## 4. 刻意不放的东西

| 不放 | 为什么 |
|---|---|
| 指数当日涨跌、实时报价、K 线 | 价格日波动与企业价值无关；放了就会诱发反应。顶部导航以外，本页不出现任何"今天" |
| 宏观新闻流、快讯 | 巴菲特 2013 年信：宏观观点和预测是浪费时间；新闻是预测的原料 |
| GDP/CPI/非农等数据"超预期/不及预期" | 预期差是短线交易者的语言 |
| 美联储议息、点阵图、降息概率 | 猜测政策 = 预测；只看已经发生的长期利率水平 |
| 经济学家/机构的预测、目标点位、衰退概率 | 三人一致反对预测 |
| 收益率曲线倒挂作为"信号" | 本质是衰退预测工具；10 年期利率水平已足够表达"引力" |
| 技术指标（均线、RSI、MACD）、资金流向、北向资金、市场温度/情绪日度指数、VIX 日度 | 动量与情绪的短期读数，和价值无关；极端情绪已由 ⑤ 的两极信号覆盖 |
| 汇率日线 | 港币联汇不需要；人民币汇率只作为长期坐标里的背景（可后续加年线） |
| 板块轮动、热点主题 | 能力圈之外的噪音 |
| 1 日 / 1 周 / 1 月时间切换 | 最短月度，默认 20 年 |
| 推送提醒（"CAPE 创新高！"） | 不做宏观推送；唯一允许的提醒是"你的某只标的进入击球区"，它属于自选页 |

## 5. 与资产 / 自选页的联动

- **宏观 → 自选**：⑥ 中每个数字可点击，跳到 `index.html` 并预置筛选（如 `?zone=deep&market=hk`）。市场钟摆进入击球区/低估时，自选页顶部出现一条暖黄提示块："港股整体处于低估水位，你的港股自选有 N 只估值超过 180 天未更新"——引导更新估值，而不是引导下单。
- **宏观 → 资产**：⑦ 反向清单读取持仓所在区间、集中度、杠杆。市场处于高估/泡沫水位时，资产页显示"组合中 X% 的仓位处于高估或泡沫区"，只陈述不建议。
- **安全边际联动（可选，后续）**：允许用户开启"按市场水位调节安全边际"——市场在高估/泡沫区时，估值工作台默认的 `mos` 提高若干个百分点（显示为建议值，用户确认）。这正是"宏观只调节安全边际厚度"的落地方式。
- **自选 → 宏观**：自选卡片不显示宏观信息（保持干净）；只在市场标签（美股/港股/A 股）上加一个小色点表示该市场水位区间，hover 显示"美股水位：高估（82 分位）"。

## 6. MVP vs 后续（含数据可得性）

### 数据源可行性
| 指标 | 市场 | 来源 | 免费？ | 难度 / 备注 |
|---|---|---|---|---|
| 10 年国债、10 年 TIPS 实际利率 | 美 | FRED `DGS10` / `DFII10` | 是（需免费 API key） | 低 |
| 总市值 / GDP | 美 | FRED `NCBEILQ027S`（Z.1 非金融企业股权市值，季度）÷ `GDP`；日度可用 Wilshire 5000 但 FRED 已停更 | 是 | 低；季度足够 |
| Shiller CAPE | 美 | shillerdata.com 月度 xls（原 Yale 页面已迁移） | 是 | 中：需解析 xls，月更，存 D1 |
| 信用利差 | 美 | FRED `BAA10Y`（长历史）；ICE 高收益 OAS 在 FRED 上历史已截短，不适合百分位 | 是 | 低 |
| CPI | 美 | FRED `CPIAUCSL` | 是 | 低 |
| 恒指 PE / PB / 股息率 | 港 | **已接 PE**：乐咕乐股 `legulegu.com/stockdata/market/hsi` 服务端渲染表格（源自恒生指数公司，1973 年起月度）；PB / 股息率在该站要 token 的接口里，暂未接。Longbridge `valuation_history` 对 HSI.HK 返回空、对 2800.HK 是 ETF 的 P/NAV，都不能用 | 免费 | 低：每周抓一次网页 |
| 香港 CPI | 港 | 政府统计处 | 是 | 中 |
| 沪深 300 / 中证全指 PE、PB、股息率 | A | 中证指数官网下载；eastmoney 指数估值接口（repo 已接 eastmoney） | 是 | 中：非官方接口可能变动 |
| 10 年国债 | 中 | eastmoney 中美国债收益率接口 / 中债 | 是 | 低中 |
| A 股总市值 / GDP | A | 沪深交易所月度统计（总市值）÷ 国家统计局季度 GDP（滚动 4 季） | 是 | 中：两源拼接 |
| CPI / PPI | 中 | 国家统计局 | 是 | 中（接口不稳定，可按月手动/半自动） |
| 两融余额 | A | eastmoney / 交易所 | 是 | 低中 |
| 长期坐标（城镇化、人均 GDP 比、研发） | 全 | 世界银行 WDI API | 是 | 低，年更 |
| 自选区间分布及其历史 | 全 | 本站 D1（需新增每日/每周快照表） | — | 低，纯内部 |

存储：Worker cron（月初 + 每周一次兜底）拉取 → D1 表 `macro_series(series_id, date, value)`；前端只读本站 API，不直连第三方（与 `/api/logo` 代理同一思路）。历史回填一次性脚本完成。

### MVP（v1）
1. **页头一句话判定**（规则生成，不用 AI）。
2. **市场水位钟摆：美股 + A 股**（港股先用恒指 PE 单项，若回填困难则标"数据建设中"斜纹空位——符合 DESIGN.md"斜纹专指空位"）。
   - 美股：市值/GDP + CAPE + 盈利收益率−实际利率
   - A 股：中证全指或沪深 300 PE/PB 百分位 + 股债性价比
3. **引力长线图**（美 10Y、中 10Y 与对应盈利收益率）。
4. **你的击球区**：当前分布 + 击球区标的列表 + 跳转自选（不含历史温度计，因需先积累快照；v1 上线即开始记录快照）。
