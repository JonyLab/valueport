# 估值方法与计算口径

应用提供 18 个计算器，统一支持单场景、保守／乐观场景、保存和复核。分类由 `public/shared/valuation/index.js` 维护，方法说明页为 `/valuation`。

| 分类 | 方法 |
| --- | --- |
| 内在估值 | FCFF、直接现金流简化 FCFF、FCFE、DDM、资源 NAV、APV |
| 相对定价 | P/E、PEG、EV/EBITDA、P/B、P/S、EV/Sales、Tobin’s Q、行业特定乘数 |
| 或有权益 | 项目／专利期权、困境企业股权（同一计算器的两种模式） |
| 资产基础 | 清算价值、NCAV |
| 组合框架 | SOTP |

经调整 P/E 使用 P/E 计算器，调整后的盈利是输入口径，不是另一套公式。PEG = P/E ÷ 盈利增速百分数；不存在通用的合理 PEG 阈值。

## 新增方法

- **APV**：无杠杆经营现金流现值 + 利息税盾现值 + 其他融资效应现值 − 财务困境成本现值 − 债务市场价值 + 非经营现金 − 其他索偿。支持等额还本和到期一次还本；税盾按每年期初本金计算，仅延续至到期。续借税盾须单独估计，不能自动假定永久续借。经营现金流使用无杠杆资本成本，税盾单独折现。
- **或有权益**：欧式 Black–Scholes 看涨期权近似。项目模式将归属期权价值加到不含该项目的业务价值，随后转为股权价值；困境模式直接以公司资产现值及到期优先债务计算股权，不再次减债。利率为连续复利，波动率为资产价值波动率。未实现美式提前行权、多阶段投资树或临床成功概率树。
- **清算价值**：可用现金 + 延迟变现所得减清算费用的现值 − 当前全部负债清偿额 − 其他优先索偿。分别输入应收款、存货、固定资产及其他资产回收率；普通股价值下限为零，明细保留截零前缺口。
- **NCAV**：流动资产 − 全部负债（含长期）− 其他优先索偿。展示原始 NCAV；每股研究价格用非负 NCAV 乘用户采用比例，再除股数。
- **EV/Sales**：营收 × 企业收入倍数 − 净负债 − 其他索偿，再除股数。营收和倍数须同期间；不自动增长或折现。
- **Tobin’s Q**：经营资产重置成本 × 同口径目标 Q − 净负债 − 其他索偿，再除股数。重置成本不含单列现金，不能直接用账面净资产替代。
- **行业乘数**：支持 EV/活跃用户、P/GMV、EV/权益可采储量。EV 模式扣净负债及其他索偿，P/GMV 直接得到股权价值。用户定义、报告期、商品和储量单位须一致。
- **SOTP**：每个分部选择方法，先求股权现值，乘持股比例和汇率，然后加总。分部可用 PE、PS、EV/EBITDA、EV/Sales、FCFF、直接 FCF、FCFE、DDM、PB、APV、项目期权、清算、NCAV、Q 或已评估现值。最多 12 个分部。集团层面只处理尚未分配的净负债、非经营资产、总部成本和其他索偿；控股折价默认零。

## 日期、金额和保存

普通模型金额与股价使用同一币种，股份数使用实际股数；百分比输入百分数，例如 10 表示 10%。SOTP 分部使用各自币种，汇率为每单位分部币种对应的报价币种金额。分部净资产和股息输入总额，最终只除一次集团股份数。

PE、PS、EV/EBITDA 的独立计算器延续预测期末价格口径；用于 SOTP 时会按分部股权折现率折到今天，EV/EBITDA 扣预测期末净负债。手填分部估值必须已经是现值。集团财务数据不会自动复制进每个分部。

清算、NCAV 和或有权益模型允许保存零股权研究结果。零价格或两位小数下不能形成有效区间的结果不会设为钟摆区间；单场景可以设置正数的单点价格。研究卡保留原始计算精度。

模型参数的默认值是可编辑假设，不代表公司事实。资料缺失时应补充依据，AI 不得虚构财务数据或将集团收入重复分配给多个业务。
